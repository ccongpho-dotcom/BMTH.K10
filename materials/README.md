# Tài liệu bài giảng

Đặt tệp PDF vào thư mục này, ví dụ:

- `chu-de-1.pdf`
- `chu-de-2.pdf`
- `chu-de-3.pdf`
- `chu-de-4.pdf`
- `chu-de-5.pdf`

Sau đó mở `data/topics.js` và sửa trường `document` của từng chủ đề, ví dụ:

```js
document: "materials/chu-de-1.pdf"
```

Nên tối ưu dung lượng mỗi tệp PDF trước khi tải lên để website mở nhanh hơn.
